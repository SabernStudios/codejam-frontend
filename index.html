CodeJam

Computer Science Honor Society

Build something. Submit it. Compete.

CodeJam is a schoolwide, GameJam-style coding competition where students create a project based on a revealed theme. You can compete alone or with a team, build in any coding environment, and submit your project before the deadline for judging, community attention, and prizes.
